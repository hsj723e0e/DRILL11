# 소년 자동 무적 런

## 실행

Python과 `pico2d`, `transitions`가 필요하다. 이미지 경로를 찾을 수 있도록 프로젝트 폴더에서 실행한다.

```powershell
python main.py
```

## 조작법

| 키 | 동작 |
| --- | --- |
| 왼쪽 / 오른쪽 방향키 | 일반 달리기. 모두 놓으면 IDLE |
| `a` | IDLE 또는 방향키로 달리는 RUN에서 자동 무적 런 시작 |
| 자동 런 중 왼쪽 / 오른쪽 | 자동 런 취소 후 누른 방향으로 일반 달리기 |
| Space | SLEEP 상태에서 깨우기 |
| Esc / 창 닫기 | 종료 |

자동 런은 키를 놓아도 400 px/s로 왕복하며, 크기가 2배가 된다.
좌우 끝에서 방향을 바꾸고 5초가 지나면 IDLE로 돌아간다.
`a`를 반복해서 눌러도 실행 시간이 연장되지 않는다.
진입 전에 누르고 있던 방향키의 반복 입력이나 키 해제는 자동 런을 취소하지 않는다.
방향키를 놓았다 다시 누르거나 반대 방향키를 새로 누르면 일반 RUN으로 전환한다.
IDLE에서 5초가 지나면 기존 기능대로 잠든다.

## 구성

- `main.py`: 게임 실행 및 입력 처리.
- `boy.py`: 기존 상태 머신과 AUTORUN 연결.
- `autorun.py`: `AutoRun` 클래스, 자동 이동·반사·확대·시간 종료.
- `PRD.md`: 개발 기획, 요구사항, 단계별 계획 및 검증 결과.
- `PRE.md`: 최초 요청 요구사항.

현재 게임에는 충돌이나 피해 시스템이 없으며, 무적 여부는 `boy.invincible`로 확인한다.

## 검증

```powershell
python -m unittest discover -s tests -v
python verify_graphics.py
```

첫 번째 명령은 그래픽 창 없이 20개 테스트를 실행한다.
두 번째 명령은 창을 잠깐 열어 실제 이미지와 SDL 렌더링으로 503개 프레임을 확인한다.
검증용 시계로 시간을 진행하므로 실제로 5초를 기다릴 필요가 없다.
